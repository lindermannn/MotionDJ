# MotionDJ

**English** · [Español](README.es.md)

**A DJ controller you play with your hands.** MotionDJ is a two-deck web DJ console driven by hand gestures in front of a webcam (mouse, keyboard and touch work too). A beginner can mix two songs in minutes; an experienced DJ gets real depth: an estimated beat grid, SYNC with phase alignment, a jog wheel that scrubs with audio in both directions, and gesture effects that land on the beat.

Built during the **Meta Global AI Developer Hackathon**. It uses **Meta Demucs v4** (open weights, running locally on your GPU) to split any track into stems — vocals, drums, bass and the rest — so you can play with each part using your hands.

> The interface is in Spanish. Labels you will see: **FRENO** = brake, **SUBIDA** = build-up, **FILTRO** = filter, **ECO** = echo, **VOZ / BATERÍA / BAJO / RESTO** = vocals / drums / bass / other, **Vista fácil** = easy view.

## How Meta Demucs is used

1. When you load a track, the app sends it to a small local server (`stems-server/`, `127.0.0.1:8765`).
2. The server runs **Meta Demucs v4 (`htdemucs`)** and separates it into 4 stems (about 13 s per song on an RTX 3060 Ti).
3. The browser plays the 4 stems in sync through Web Audio. Every hand effect can target one stem: roll only the drums, echo only the vocals, brake everything except the vocals, mute or unmute parts on the beat.

Everything stays on your machine: your songs and the stems cache are never uploaded anywhere. If the server is not running, MotionDJ works the same with the full track.

## Run it

Requirements: Node.js 20+ and Chrome or Edge (Web Audio + `getUserMedia`). **No internet needed**: the hand-tracking model and its WASM are bundled in the project.

```powershell
npm install
npm run dev
```

Open http://127.0.0.1:5173, click **Activar audio** (enable audio), then **Cargar demos** (two tracks generated by the app itself, no copyrighted music) or import your own music. Your files are processed in your browser and never leave your computer.

### Optional: stems server (Meta Demucs)

Requires Python 3.10+, [Demucs](https://github.com/facebookresearch/demucs) 4.x and PyTorch (a CUDA GPU is recommended; CPU works but is slow).

```powershell
python -m venv venv
.\venv\Scripts\pip install demucs torch torchaudio
.\venv\Scripts\python stems-server\server.py --cache .\stems-cache
```

Options: `--host`, `--port`, `--cache`, `--device` (`cuda` or `cpu`). `stems-server/start.ps1` is the author's launcher with local paths. API details in [stems-server/README.md](stems-server/README.md).

For a static build: `npm run build` creates `dist/` (works on Vercel, Netlify or any static host; the camera requires HTTPS or localhost).

## Hand mode (MANOS · FX)

Press **MANOS · FX** on a deck, pick an effect with a pinch, and the console steps aside so your hands take over. Take both hands out of the frame to leave.

| Effect | Gesture | What it does |
|---|---|---|
| **FILTER** (FILTRO) | Pinch with both hands and stretch, like a string | Sweeps the filter; bring hands together to close it |
| **ECHO** (ECO) | Close your fist ~0.3 s to grab the song, raise it for more echo, thumbs up to throw | Echo-out that throws the mix to the other deck (A→B→A); a second fist controls the echo tail |
| **LOOP ROLL** | Raise 1, 2 or 3 fingers | Rolls 1, ½ or ¼ beat from the next beat; close the hand and the track continues where it would have been |
| **BRAKE** (FRENO) | Hold a still "stop" palm ~0.4 s | Vinyl-style brake; comes back on the beat, in place |
| **BUILD-UP → DROP** (SUBIDA) | Open both hands, raise them; press palms together | Drums roll faster, bass drops out, high-pass opens, vocals stay clean; palms together drops everything back on the next bar |
| **STEMS** | Pinch VOCALS, DRUMS, BASS or OTHER | Mutes or unmutes that part on the beat; two pinches set its volume |

## Console features

- **Two decks** with PLAY/CUE/SYNC, ±8 % tempo with a center detent, 4-beat loop, full and zoomed waveforms (4/8/16 s) to see the grid over the kicks.
- **Mixer**: EQ −26…+6 dB, TRIM, one-knob FILTER, BPM-synced ECHO per channel, faders, crossfader, MASTER, limiter with a measured ceiling and warnings for clipping and "two bass lines".
- **Jog wheel that works**: the center scrubs **with audio forward and backward** (custom AudioWorklet); the edge nudges the tempo and springs back.
- **Fixed pads**: 2 hot cues, 2 four-beat jumps, 2 effects and 2 sounds. No mode switching.
- **Track picker** full screen: choose the next track with your fingers while the other one plays, with a per-deck queue.
- **Pinch to grab any control** (no jumps), stable hand identity when hands cross, CROP/FULL framing with the pointer following your finger.
- **Auto DJ** A↔B, smooth transition, record your mix to `.webm`, an **easy view** without jargon, and "match and mix" in one button.
- **Headphone cue**: a separate output you choose (`setSinkId`), e.g. headphones, to pre-listen to the next deck while the mix plays on the main output; not included in the recording. Tested with two real outputs.

Keyboard: `Q`/`A` deck A · `P`/`L` deck B · `←` `→` crossfader · `G` pause gestures without stopping the music · `F` fullscreen · `Esc` leave hand mode.

## What is estimated or limited

- **BPM is estimated** by our own analysis. SYNC matches the effective BPM and aligns the phase to that grid; it is not infallible beatmatching.
- Tempo also changes pitch (no time-stretch).
- The webcam sees hands in 2D: no depth and no real contact.
- No key detection and no microphone.

## Tech stack

- **Meta Demucs v4** (`htdemucs`, MIT) — local stem separation on GPU
- **MediaPipe Hand Landmarker** (Apache-2.0, Google) — 21 hand landmarks per hand, bundled in `public/mediapipe/`
- **Web Audio API** + AudioWorklet — all mixing, effects and scrubbing in the browser
- **Vite** (MIT) — build only; the app is vanilla JavaScript

The rest is original code and sound synthesis; details in `docs/licencias.md`. Project docs (in Spanish) are in `docs/`.
